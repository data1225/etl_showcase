4勝出客群分析

客群二 (WFH 專業工作者) 在 CPA、CVR、ROAS、CTR 全面勝出，是第二輪投放的核心錨點。

Winner Persona

WFH／工程師／設計師／剪輯師 (25-40 歲)

  • 生活樣態：居家工作 6-10 小時，下班後仍有副業或創作，視覺勞動是日常。
  • 心理動機：追求「下班後屬於自己的時間」感受，把工作工具升維成生活陪伴。
  • 消費特性：對「規格」與「設計感」並重，看到 RA97、5 段色溫、50 分鐘提醒會有共鳴。
  • 決策路徑：IG 看到廣告 → FB 查口碑 → 蝦皮/官網下單；單次客單可達 NT$3,000+ 不眨眼。
「它不催你。不評判你。只是在那裡，陪你把那件事做出來。」

主要痛點對位

• 下班後想做副業，但容易疲倦 → RA97 高演色 + 5 色溫
• 螢幕看 8 小時眼睛酸 → 50 分鐘休息提醒
• 桌面美學重要 → 鈦珈白 + 鋁合金
• 預算彈性高、價格敏感度低 → 主打「陪伴 + 創造力」而非「便宜」

5第二輪廣告策略

以客群二勝出邏輯為錨點，向四個市調訴求各自延展。建議：方向三為主推、方向一為信任放大器、方向四為高客單價拓展、方向二為測試新客群。

方向一｜專業挑剔型 · 信任放大器

「3 成叫護眼燈的，根本不護眼。」

能被實驗數據證明的護眼，才叫護眼。
核心訴求
用消基會調查 + RA97 + 實驗報告，把「假護眼燈」當對手打。
目標受眾
30-50 歲 3C 重度比價型、已有一盞想升級者
建議平台
Facebook (主) + YouTube (15s 短測評貼片)
素材格式
長文圖卡 + 30s 數據動畫影片 + 認證標章橫幅
預估效果
CTR +20-30%；CVR 與本輪相近，客單拉升
文案範例：「消基會抽驗：30% 自稱護眼燈商品 RA 連 80 都不到。我們把 RA97 寫進規格、寫進保固。」
方向三｜生活質感派 · ★主推

「工作桌的小升級，下班後也捨不得關。」

每晚都想回到的書桌，從這盞燈開始。
核心訴求
把護眼燈定位為「生活風格 + 自我陪伴」，銜接勝出廣告精神。
目標受眾
25-35 歲都會工作族群 / 自由接案 / Dcard 桌面 setup 重度搜尋者
建議平台
Instagram (主) + Facebook + Threads
素材格式
Reels/Story 15-30s
預估效果
CTR +15-25%；CPA 預估再降 15-25%；ROAS 上看 6.0+
主推原因
因為此方向跟第一輪勝出廣告的情緒定位最連貫，目標受眾非部份重疊而是完全重疊（WFH 專業者），複製成功經驗的機率最高、風險最低。
文案範例：「不是檯燈，是我把工作桌變回自己房間的那個 switch。」

目標受眾

建議平台

關鍵注意事項

  • 樣本量提醒：本輪含 2 個意外日 + 歸因衰減，d=0.75 為大效果但非極端；對單一平台仍偏小，建議第二輪拉長到 21 天或加倍預算以提高單平台統計力。
  • X 平台處置：CPA 最高且 CVR 不穩，建議第二輪暫停 X，把預算移到 IG/FB。
  • 創意疲乏：同一支素材曝光超過 3-5 次後 CTR 會衰退，建議每 7 天輪換。
  • 歸因視窗：本輪已模擬 30% 延遲歸因；實際應啟用 7 天點擊 / 1 天曝光跨平台歸因。
  • 意外日應變：本輪意外日影響 CPM 翻倍、CTR 砍半；建議監控素材審核狀態並有備用素材。
  • 學習期保護：第二輪建議前 3 天不調整素材、預算，讓平台演算法穩定收斂。

模擬數據產生依據

  • CPM 參考來源
    • 台灣 Facebook／Instagram 廣告 CPM 參考Meta Ads Manager 台灣市場公開數據區間（2023–2024），家電／3C 周邊品類平均 CPM 約 NT$150–220。
    • YouTube CPM 參考 Google Ads 台灣市場健康家電類別平均區間 NT$120–160。
    • X（Twitter）台灣廣告市場規模較小，CPM 取保守值NT$100–130。
  • CTR 參考來源
    • Meta 官方 Benchmark Report（2024）顯示，台灣消費性電子品類平均 CTR 約 1.0–2.0%。
    • 客群二（WFH／工程師／設計師）因長期主動關注桌面裝備升級， 看到相關廣告的點擊意願顯著高於一般消費者 ，CTR 取區間上緣。
    • 客群一（學齡兒童家長）看到廣告前未必有明確購買意圖，需經由廣告內容建立問題意識後才產生點擊行為， 初次接觸的點擊率因此低於已有明確需求的客群二，CTR 取區間中段。
  • 轉換率參考來源
    • 台灣電商平均轉換率約 1.0–3.0%（資料來源：91APP 台灣電商報告 2023、ECFIT 電商數據報告）。
    • 護眼燈屬中高考慮型商品（售價 NT$3,000），客群二因自主消費能力強、決策週期短，轉換率設定為 2.2%。
    • 客群一因需家庭共識，設定為 1.8%。
  • 數據局限性說明
    • 本模擬未納入實際廣告帳號歷史數據、季節性波動（如開學季需求高峰）等變數，但有在14日中隨機加入1-2日意外日(可能原因為素材被審核下架、競品大促、平台演算法臨時調整等)。
    • YouTube 及 X 平台數據因台灣品類公開資料較少，採保守估算，實際投放結果可能有所差異。
    • 核心統計結論以 Facebook 及 Instagram 數據為主要依據。
